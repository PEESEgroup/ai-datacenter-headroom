# 22 October 2026 update

This release retains the existing package layout and standardized-input workflow.
It adds the reviewed project-capacity attributes, current geographic sensitivity
results and documented POWER/EIA physical-hour matching. It also supplies the
native-ledger and within-PJM mapping tables used in the regional comparisons.

The annual runner rebuilds the full-precision scenario results and figure/table
data. The targeted follow-up can be run separately. No manuscript, Supplementary
Information, reviewer correspondence, publication figures, local audit logs,
compiled libraries or bulk upstream weather archives are included.

The framework rules are in `FRAMEWORK_RULES.json`; input definitions and source
scope are in `INPUTS_AND_SCOPE.md`. Run instructions are in `README.md`.
Earlier versions remain accessible in the repository history.
